# Mans-oHollow
Mansão Hollow, um jogo de terror em HTML, CSS e JavaScript (Canvas), que roda direto no navegador.  História: você acordou preso numa mansão abandonada. À meia-noite o ritual termina e algo vai despertar. Você tem 60 segundos para acender 5 velas 🕯️ no escuro e escapar pela porta 🚪, enquanto um fantasma 👻 caça você.
